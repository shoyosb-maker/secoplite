⚠️ NOTA SOBRE "file://" ERROR
═══════════════════════════════════════════════════════════════════════════════

El error de seguridad "Unsafe attempt to load URL file://..." es NORMAL cuando
abres archivos HTML localmente. NO es un problema real.

SOLUCIÓN:

    • Python:    python -m http.server 8000
    • Node:      npx http-server
    • VSCode:    Instala "Live Server" extension
    
  - O ignora el warning en desarrollo (desaparece en producción)
